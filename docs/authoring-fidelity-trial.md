## Evaluation and stopping rule

Prepare a private fact ledger before authoring, referencing each supplied material
fact and forbidden inference. The reviewer receives packets, ledger and immutable
outputs only after submission, and independently validates/renders as needed.
Report per case:

1. Selection and reason, including justified declines.
2. Actual invocation and syntax (distinct from semantic labels).
3. Fidelity: every predeclared material fact, named unknown, explicit unavailable
   state, unit, time basis, source/scope and consequential qualification preserved;
   no invented total, certainty, recommendation, equivalence, causality or status.
4. Rendered association: claims retain item or alternative/criterion ownership and
   qualifications, with no silent loss through wrapping/scrolling.
5. Effort: actual errors, repairs, inspection coverage and scrolling costs.

A case fails fidelity on any material omission or unsupported claim. A faithful
prose response can pass fidelity while failing an independently justified selection
expectation. Shape validity cannot establish truth. Readable JSON is not proof of
rendered coverage. Document uncertainty and evidence limits rather than substituting
a keyword check for semantic review.

Stop after one author run and independent review. A rendering defect or contract
limit is a result, not permission to repair the visuals mid-trial. No coached
rerun, framework, sanitizing resolver, schema expansion or production code.

Return a compact evidence table and one consequential tradeoff to Travis: **does
faithful qualification handling retain the visual-parsing benefit at an acceptable
scrolling and authoring cost?** Five clean cases still cannot establish broad
reliability, improved decisions or human comprehension. Existing positive visual
feedback remains accepted evidence, not a result to re-prove or redesign.

Run `./scripts/check` for the documentation/evidence changes and verify protected
file hashes. Dependency versions are unchanged; no new audit/CI claim is implied.
